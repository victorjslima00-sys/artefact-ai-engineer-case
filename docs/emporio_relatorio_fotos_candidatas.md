## Instruções para integração

1. Relacione a imagem pelo `id` do produto, nunca apenas pelo nome.
2. Confira acabamento, cor, número de cordas, tamanho e variante antes de ativar a imagem.
3. Hospede os arquivos autorizados localmente, por exemplo em `static/images/products/<id>.webp`.
4. Se não houver foto confiável, use placeholder elegante e mantenha o produto marcado internamente para revisão.
5. Não use fotos de outro modelo apenas para preencher espaços vazios.
6. O carrossel deve ler as imagens do campo de imagem do produto e nunca renderizar strings HTML como texto.
